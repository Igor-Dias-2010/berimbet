# BerimBET

Este é um simulador de palpites esportivos estritamente fictício e recreativo. Ele foi criado exclusivamente para fins de entretenimento, teste de lógica e estudo de desenvolvimento.

🚫 Aqui NÃO existe dinheiro real:
• É impossível depositar dinheiro (não há Pix, cartão ou boleto).
• É impossível sacar qualquer valor.
• Os saldos, pontos e fichas exibidos pertencem apenas ao ambiente virtual do jogo e não possuem valor financeiro no mundo real.
